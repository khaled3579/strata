# Strata Project Web

هذه النسخة مبنية على Strata 0.2.13. يشغّل Strata نماذج الذكاء الاصطناعي محليًا، ويوفر محادثة في المتصفح، وواجهة لمراقبة الخادم، وتطبيق سطح مكتب، وأدوات طرفية، وواجهات API متوافقة مع OpenAI وAnthropic. تركز تعديلات هذه النسخة على العمل على مشروع محلي من واجهة الويب.

## التعديلات في هذه النسخة

- يجري **اختبار التشغيل في المتصفح** بعد نجاح البناء عند تفعيله. يعرض تقرير التحقق صفحة الاختبار ورمز HTTP وعنوان الصفحة وأخطاء المتصفح، أو سبب تعذّر الفحص.
- تعرض **إعدادات الفحص** أوامر البناء والاختبار المكتشفة للمجلد المختار. يمكن تعديل الأمر ومجلد تشغيله وحفظهما للمشروع، أو العودة إلى الاكتشاف التلقائي. تعرض بطاقة التحقق اسم التبعية المفقودة والأمر المتأثر عندما تكشف المخرجات عنها.
- يظهر زر **عرض التغييرات** بعد الرد الذي سجّل تعديلات على المشروع. يعرض الملفات المضافة والمحذوفة والمعدّلة، مع مقارنة قبل وبعد للملفات النصية القابلة للعرض.
- يتيح **التراجع عن تعديلات هذا الرد** استعادة حالة الملفات قبل آخر رد عدّل المشروع. إذا تغيّر ملف معني بعد الرد، يوقف Strata التراجع. يُحفظ سجل التغييرات في ذاكرة الخادم للجلسة الحالية.
- تظهر بطاقة **تقرير التحقق** داخل المحادثة قبل الرد النهائي. تعرض حالة البناء والاختبارات، وعدد الاختبارات الذي أبلغت عنه أدوات الفحص، وأول خطأ مع اسم الملف والسطر عند توفرهما، والفحوص التي لم تُنفّذ أو لم تُكتشف.
- ترتبط نتائج البطاقة بنسخة الملفات التي فُحصت. عند تغيّر الملفات، تظهر رسالة **«تغيّرت الملفات. أعد تشغيل الفحص.»**. ويمكن الرجوع إلى البطاقة في المحادثة المحفوظة.
- مستكشف مشروع قابل للطي في الشريط الجانبي. يتيح اختيار المجلد وتغييره، وفتح فروع الشجرة، وعرض الملفات الجديدة تلقائيًا. يفحص جذر المشروع والفروع المفتوحة دوريًا أثناء ظهور اللوحة.
- عند تفعيل منتقي Windows، يرتبط المجلد بالمحادثة التي اختارته. تبدأ المحادثة الجديدة بلا مشروع، وتستعيد المحادثة المحفوظة مجلدها ضمن جلسة الخادم نفسها. بعد إعادة تشغيل الخادم، اختر المجلد مجددًا.
- تصميم جديد للشريط الجانبي مع تمييز الملف المحدد وأيقونات لأنواع الملفات. النقر على الملف يفتح معاينة محلية للنص أو الكود أو الصور المدعومة. تُعرض ملفات HTML وSVG كنص عند معاينتها من المستكشف.
- قائمة بالزر الأيمن أو زر **⋯** لمعاينة الملف أو إظهار موقعه في Windows File Explorer أو فتحه في VS Code. يتحقق الخادم من وجود الملف داخل المجلد المختار قبل فتحه.
- زر **Save code** بجانب كتل الكود في الردود. يفتح منتقي الحفظ في مجلد المشروع، ويكتب الكود إلى الملف الذي يختاره المستخدم ويؤكد حفظه.
- دعم RTL وLTR في حقل المحادثة، ورسائل المستخدم، والفقرات والعناوين والقوائم والجداول. تبقى أوامر الطرفية ومسارات الملفات داخل تنسيق الكود بالاتجاه LTR.
- دعم تنفيذ مهام المشروع باستخدام خادم ملفات MCP. عند طلب التنفيذ أو المتابعة، توجه واجهة الويب النموذج لإنشاء الملفات والمجلدات المطلوبة ضمن المشروع دون موافقة منفصلة على كل خطوة. يرفع إعداد التشغيل المقترح حد الأدوات من 8 إلى 32 جولة لكل رد.
- عند اقتراب محادثة نصية تستخدم أدوات MCP من حد السياق، يستطيع الخادم استبعاد الرسائل وجولات الأدوات الأقدم من السياق المرسل إلى النموذج. يحتفظ بالطلب الحالي وأحدث جولة أدوات، وتبقى المحادثة الكاملة محفوظة في المتصفح.
- يكتشف Strata أوامر البناء والاختبار لمشاريع Node.js وPython وRust وCMake. بعد تعديل الملفات، يشغّل الفحوص على نسخة مؤقتة في Windows AppContainer دون اتصال بالشبكة. تظهر حالة كل أمر ورمز خروجه ومخرجاته في المحادثة قبل التسليم.
- تتضمن نسخة المحرك تغييرات في تخزين سياق المحادثة، وتحميل خبراء النموذج، وأخذ العينات والتحقق التخميني عند تقسيم العمل على أكثر من بطاقة.
- تشغيل خادم الويب ومساعد Windows عبر «جدولة المهام» لتشغيلهما عند تسجيل الدخول واستمرارهما مستقلين عن تطبيق Codex.

## إعداد المشروع على Windows

1. اتبع [دليل تثبيت Strata](INSTALL.md) لإعداد المحرك والنموذج وإنشاء ملف إعداد تشغيل محلي. يحتاج منتقي Windows إلى Python مع Tkinter وجلسة سطح مكتب مفتوحة. يدعم Chrome وEdge حفظ كتل الكود من الواجهة.
2. ثبّت أداة ملفات MCP في مجلد محلي خارج المستودع. هذا المثال يستخدم الإصدار الذي اختُبر مع النسخة.

   ```powershell
   $toolDir = Join-Path $env:LOCALAPPDATA 'Strata\ProjectTools'
   npm.cmd install --prefix $toolDir --no-audit --no-fund --save-exact @modelcontextprotocol/server-filesystem@2.2.0
   (Get-Command node.exe).Source
   Join-Path $toolDir 'node_modules\@modelcontextprotocol\server-filesystem\dist\index.js'
   ```

3. ادمج المفاتيح التالية مع ملف إعداد النموذج الحالي، مع استبدال المسارات بأخرى موجودة على جهازك. مسار `cwd` ومسار المشروع في `args` يشيران إلى المجلد نفسه.

   ```json
   {
     "mcp_servers": {
       "project_files": {
         "project_picker": true,
         "command": "C:/Program Files/nodejs/node.exe",
         "args": [
           "C:/path/to/ProjectTools/node_modules/@modelcontextprotocol/server-filesystem/dist/index.js",
           "C:/path/to/project"
         ],
         "cwd": "C:/path/to/project",
         "project_checks": {
           "node": "C:/Program Files/nodejs/node.exe",
           "cmake": "C:/Program Files/CMake/bin/cmake.exe"
         }
       }
     },
     "mcp": {
       "max_rounds": 32,
       "compact_history": true
     }
   }
   ```

4. أوقف أي مثيل يعمل على المنفذ 8080 قبل بدء التشغيل المجدول. من مجلد المستودع شغّل الأمر التالي، مع تمرير ملف الإعداد المحلي الفعلي. إذا كانت بيئة Python في مسار مختلف، مرّره عبر `-Python`.

   ```powershell
   .\tools\register-project-web.ps1 -Config 'C:\path\to\strata-model.json' -Start
   ```

5. افتح [واجهة Strata المحلية](http://127.0.0.1:8080/) واختر المجلد في **Project**. تحقق من اتصال `project_files` في **Monitor** وفعّل **Use tools from MCP servers** في إعدادات المحادثة.

## نطاق الوصول

عند تفعيل `project_picker`، يفتح زر **Choose folder** منتقي Windows. يحدد اختيارك نطاق القراءة والكتابة للمحادثة، ضمن صلاحيات حساب ويندوز. يمكن اختيار مجلد مشروع من أي قرص يصل إليه الحساب. يدعم الخادم هذا المسار من واجهته على الجهاز المحلي.

عند تعطيل `project_picker`، يعرض مستكشف المتصفح المجلد بإذن القراءة، ويستمر MCP ومساعد Windows على مسار الإعداد الثابت. يتطلب **Open in VS Code** تثبيت VS Code في أحد مسارات التثبيت القياسية.

## الفحص المعزول

فعّل `project_checks` كما في المثال لتشغيل الفحوص بعد تعديلات المحادثة، أو اطلب «افحص المشروع الآن». يستخدم Python نسخة التشغيل المحلية. يحتاج Rust وCMake مع MSVC إلى مسار اختياري باسم `native` يحوي مجلدات `rust` و`msvc` و`sdk` والأرشيف المحلي `registry` عند الحاجة. يشير `python_packages` اختياريًا إلى مجلد حزم محلي يوفر pytest وتبعياته. يمكن ضبط `scratch` على مجلد موجود خارج المشروع لتخزين النسخ المؤقتة.

بعد اختيار المجلد، افتح **إعدادات الفحص** من لوحة المشروع. أدخل الأداة والوسائط كمصفوفة JSON، مثل `["npm","test"]`، وحدد مجلد تشغيل نسبيًا مثل `src-tauri` أو `.` لجذر المشروع. يحفظ Strata الأوامر في `.strata-checks.json` ويستخدمها في الفحص التالي. يزيل خيار **استخدام الأوامر المكتشفة** التخصيص ويعيد الاكتشاف التلقائي.

تُشغّل الأوامر على النسخة المعزولة باستخدام الأدوات المهيأة محليًا. تعرض نتائج الفحص التبعيات الناقصة والمشاريع غير المدعومة. حد النسخة المؤقتة 100 ألف ملف و2 غيغابايت، ويُتخطى نسخ الروابط ونقاط إعادة التوجيه.

## اختبار التشغيل في المتصفح

فعّل `browser_smoke` داخل `project_checks`، واضبط `playwright` على مسار مجلد حزمة `playwright-core` المحلية. يحتاج الفحص إلى Node.js وWindows Sandbox CLI ‏(`wsb.exe`) ومتصفح Edge داخل البيئة المعزولة أو نسخة متصفح محلية مهيّأة عبر `smoke_browser`. يعمل التطبيق والمتصفح في البيئة نفسها مع تعطيل الشبكة. [متطلبات Windows Sandbox CLI](https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-cli)

يبحث Strata عن صفحة مبنية في `dist` أو `build` أو `out`، أو أمر `npm start`، أو مشروع Django. يمكن تعريف أمر تشغيل صريح لمشروع Node.js أو Python في `.strata-checks.json`، مثل:

```json
{"smoke":{"argv":["python","-m","http.server","{port}","--bind","127.0.0.1"],"page":"/"}}
```

يمكن ضبط مجلد التشغيل عبر `cwd`. يستخدم التطبيق المنفذ المحلي 4173 داخل البيئة المعزولة. يمكن توفير حزم Python اللازمة محليًا عبر `smoke_python_packages`، أو تعطيل اختبار التشغيل للمشروع عبر `"smoke": false`. عند غياب Windows Sandbox أو تعذّر تشغيله، تعرض البطاقة السبب.

## محتوى المستودع

تضم تحديثات هذه النسخة الكود المصدري والتوثيق. تُعد أوزان النماذج وملفات التشغيل الشخصية وأدوات الفحص المحلية وسجلاتها خارج المستودع. يتضمن تاريخ المنبع عينات صغيرة لرؤوس تنسيق GGUF تستخدمها اختبارات المشروع.
